FocusFlow is a lightweight, zero-backend study tracking and academic planning web app built with HTML, Tailwind CSS, and Vanilla JavaScript.

Key Features:

Live Ticking Countdown (Days : Hours : Mins : Secs): Displays a real-time, second-by-second countdown to your upcoming exam, midterm, or project submission deadline.

Focus Timer & Stopwatch: Customizable Pomodoro countdowns (Focus, Short Break, Long Break) plus a live Stopwatch with lap split tracking.

Course & Syllabus Tracker: Organize courses with weekly hour targets and interactive chapter checklists.

Assignments & Task Planner: Track homework and deadlines with priority tags and status filters.

Visual Analytics: Track daily streaks, weekly study hours, and goal progress in Light or Dark mode.

Private Local Storage & JSON Backup: All data stays privately in the user's browser with one-click JSON export and restore.
